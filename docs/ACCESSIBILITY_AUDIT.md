## Findings addressed

The Welcome placeholder did not teach controls or provide practice. Several pages relied on manual announcement calls, leaving newer pages without one. Fixed corner camera controls could overlap at large text/short landscape heights. Switch labels and state pills competed horizontally at large text. Disabled buttons reduced text contrast through opacity. The hidden version control had an action but a text role/no hint. Framing triggered React updates for every packet even when its spoken state was unchanged; background expiry repeatedly published empty arrays; disabled feedback kept a watchdog interval. These code findings are addressed in Phase 7 and covered by the linked behavior/component/route tests.

iOS volume capture requires the public camera-session interaction already used by Lumi. Guided access therefore precedes preview practice. Camera denial/unsupported hardware must keep the button path usable. No private volume observer, silent microphone capture, extra cloud service or new native dependency is introduced.
